# Sources utilisées

Toutes les sources citées dans `02-recherche.md`, classées par section du dossier.

- **Date** = date de publication quand elle est connue. Toutes les sources ont été consultées le **11 novembre 2026**.

- Wikipédia n'a servi que de point de départ, jamais de preuve unique.
